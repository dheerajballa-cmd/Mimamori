## Overview

Fine-tuning of a dual-head forecasting module (short-horizon 3–7 day and
long-horizon 4–8 week) built on top of the pretrained Mimamori encoder
(NHATS longitudinal wellness survey data). A from-scratch encoder baseline
(same architecture, random initialization) is evaluated to validate that
pretraining provides measurable benefit.

---

## Proxy Task & Known Limitation

**Dataset:** SisFall accelerometer fall/ADL trials

**Session-to-Sequence Workaround (Epic 8.2):**
SisFall contains single-session lab trials, not multi-day longitudinal
sequences. `forecast/session_to_sequence.py` concatenates each subject's
trial windows into a synthetic 'week' of T=4 timesteps.

**Domain Gap (documented limitation §16.2):**
The encoder was pretrained on NHATS longitudinal wellness surveys; SisFall
uses accelerometer fall events — structurally different inputs. This limits
absolute AUROC but pretraining consistently helps vs random initialization.
In production (Stage 4), domain-matched accelerometry data would close this gap.
