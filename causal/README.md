## 1. Why a Synthetic Dataset?

No public dataset provides **ground-truth causal structure** between sleep, routine, gait health, medication, and fall risk in elderly individuals.
Real longitudinal datasets (NHATS, eHomeSeniors) provide observational trajectories, but the causal *direction* and *strength* of relationships cannot be inferred from observations alone without an interventional study — which this project does not have.

The synthetic dataset generated by `causal/simulate.py` solves this directly:
- We **hand-specify** the causal graph (edges + effect coefficients).
- We **generate** observations from that graph, injecting known perturbations.
- We **evaluate** causal attribution methods against the known ground truth.

This is the standard approach in causal machine learning research (see: Peters et al., *Elements of Causal Inference*; Schölkopf et al., 2021).

## 2. Structural Causal Model (SCM) Specification

### 2.1 Observable Nodes

| Node | Semantics | Range | Source in Real Pipeline |
|---|---|---|---|
| `sleep_quality` | Nightly sleep depth/continuity quality index | [0, 1] | NHATS self-reported sleep items + audio-inferred nighttime activity |
| `routine_deviation` | Deviation from established daily activity pattern | [0, 1] | Daily activity timing and step-count divergence from subject rolling mean |
| `gait_stability` | Composite gait health (cadence, stride variability, sway) | [0, 1] | IMU gait features from preprocess/gait.py |
| `medication_adherence_proxy` | Self-care regularity / structured-routine proxy | [0, 1] | Inferred from activity regularity and NHATS medication-item proxies |
| `fall_risk` | Cumulative fall probability index | [0, 1] | Output of forecasting head (Epic 8) |

> **Note on `medication_adherence_proxy`**: No dataset directly measures medication adherence.
> This node is derived as a proxy from: (1) structured daily activity timing regularity, and (2) NHATS
> questionnaire items about self-care management. It is flagged as a lower-confidence node in all outputs.

> **Note on `sleep_quality`**: Derived from NHATS self-reported sleep items and audio-inferred
> nighttime activity duration from Sounds of Home. Explicitly lower-confidence than gait/routine.

---

### 2.2 Causal Graph

```
medication_adherence_proxy ──────────────────────────────────────────┐
         │                                                            │
         │ (-0.30)                                                    │ (+0.25)
         v                                                            │
  routine_deviation ──(-0.25)──> sleep_quality                       │
         │                            │                              │
         │ (-0.20)                    │ (+0.35)                      │
         │                            v                              v
         └────────────────────> gait_stability <─────────────────────┘
                                      │
                                      │ (-0.50)
                                      v
              sleep_quality ─(-0.15)─> fall_risk <──(+0.10 * age_factor)
```

**Directed edges:**

| From | To | Coefficient | Interpretation |
|---|---|---|---|
| `routine_deviation` | `sleep_quality` | −0.25 | Disrupted routine degrades sleep |
| `medication_adherence_proxy` | `routine_deviation` | −0.30 | Poor adherence increases routine disruption |
| `sleep_quality` | `gait_stability` | +0.35 | Better sleep → more stable gait (strongest path) |
| `routine_deviation` | `gait_stability` | −0.20 | Disruption degrades gait balance |
| `medication_adherence_proxy` | `gait_stability` | +0.25 | Good adherence supports physical function |
| `gait_stability` | `fall_risk` | −0.50 | Primary causal path: gait instability drives risk |
| `sleep_quality` | `fall_risk` | −0.15 | Direct path: poor sleep raises fall risk (independent of gait) |
| `age_factor` | `fall_risk` | +0.10 | Age raises baseline risk (exogenous, not intervened on) |

**Exogenous (unobserved) variables:**
- `u_sleep` — Gaussian noise on sleep quality (σ = 0.08)
- `u_routine` — Gaussian noise on routine deviation (σ = 0.07)
- `u_gait` — Gaussian noise on gait stability (σ = 0.06)
- `u_med` — Gaussian noise on medication adherence (σ = 0.09)
- `u_fall` — Gaussian noise on fall risk (σ = 0.04)

---

### 2.3 Structural Equations

Each observable node is generated by a linear structural equation with Gaussian noise:

```
medication_adherence_proxy  = 0.80 − 0.05·age_factor + u_med
routine_deviation           = 0.25 − 0.30·medication_adherence_proxy + u_routine
sleep_quality               = 0.75 − 0.25·routine_deviation + u_sleep
gait_stability              = 0.30 + 0.35·sleep_quality − 0.20·routine_deviation
                                   + 0.25·medication_adherence_proxy + u_gait
fall_risk                   = 0.50 − 0.50·gait_stability − 0.15·sleep_quality
                                   + 0.10·age_factor + u_fall
```

All values are clipped to [0, 1] after computation.

**Temporal dynamics:** An AR(1) autoregressive process (ρ = 0.70) blends the day's newly computed value with the previous day's value, producing realistic multi-day persistence:
```
x_t = 0.70 · x_{t-1} + 0.30 · f(parents_t)
```

### 2.4 Causal Scenarios and Perturbations

Six scenarios are generated with distinct root causes:

| Scenario | Perturbation | Ground-Truth Root Cause | Typical fall_risk range |
|---|---|---|---|
| `stable` | None | — | 0.10 – 0.25 |
| `sleep_driven` | `u_sleep` += 0.25 (ramps over days 1–9) | `sleep_quality` | 0.25 – 0.45 |
| `routine_driven` | `u_routine` += 0.30 (ramp) | `routine_deviation` | 0.20 – 0.40 |
| `medication_driven` | `u_med` -= 0.35 (ramp) | `medication_adherence_proxy` | 0.25 – 0.45 |
| `mixed` | `u_sleep`+=0.15, `u_routine`+=0.15, `u_med`-=0.20 | `sleep_quality` (largest effect) | 0.30 – 0.50 |
| `activity_driven` | `u_gait` -= 0.20 (ramp) | `gait_stability` | 0.25 – 0.40 |

Perturbations ramp linearly over the first 10% of simulation days (days 1–9 of 90), then hold at full amplitude — mimicking a gradual onset of health disruption.

## 4. Design Rationale (Why These Edges?)

### Why `sleep_quality → gait_stability`?
Abundant clinical evidence shows sleep deprivation impairs balance and neuromuscular coordination. This is one of the strongest mechanistic links in geriatric fall research (Rubenstein 2006, Stone et al. 2008).

### Why `routine_deviation → sleep_quality`?
Circadian rhythm disruption is a primary driver of sleep fragmentation in older adults. Irregular daily routines disturb the sleep-wake cycle (Monk et al. 1992). This is supported by NHATS data showing correlations between irregular activity timing and self-reported sleep problems.

### Why `medication_adherence_proxy → routine_deviation`?
Poor self-care regularity (medication timing, meal timing) and routine instability are strongly correlated — both reflect executive function and self-regulation capacity, which decline together.

### Why `gait_stability → fall_risk` as the dominant path?
Gait instability (cadence irregularity, stride variability, sway) is the strongest validated biomechanical predictor of fall risk in older adults across multiple systematic reviews (Hausdorff 2005, Callisaya et al. 2009). Coefficient −0.50 reflects this dominance.

### Why a direct `sleep_quality → fall_risk` edge?
There is evidence for a direct sleep → fall-risk pathway independent of gait mediation — via cognitive impairment, sedative medication response, and post-awakening disorientation. Coefficient −0.15 reflects a smaller but non-negligible direct effect.

### Why `medication_adherence_proxy` as a root node?
In the causal hierarchy, medication adherence has no causal parents among the observable nodes — it is driven by person-level factors (health literacy, cognitive status) that are not included as nodes. Making it exogenous is therefore the correct structural choice.

## 5. Known Limitations

| Limitation | Impact | Mitigation |
|---|---|---|
| Linear structural equations only | Cannot capture nonlinear dose-response effects common in clinical data | Linear SCM is standard in causal-learn/DoWhy benchmarks; nonlinear extensions are future work |
| `sleep_quality` and `medication_adherence_proxy` are proxied, not directly measured | Nodes are lower-confidence than gait/routine | Explicitly labeled in `scm_ground_truth.json`; noted as lower-confidence in `causal_metadata.json` |
| Gaussian noise model | Real health data has heavier tails and skewed distributions | Chosen for tractability; well-understood for DoWhy and PC algorithm evaluation |
| No real-world causal validation | SCM evaluation is synthetic only | Applied to real eHomeSeniors/NHATS as plausibility check (non-validating; see Epic 10.6) |
| Fall events are simulated, not observed | Field-wide limitation (all fall datasets use staged falls) | Stated plainly in any writeup, not hidden |
| `age_factor` is exogenous | Cannot intervene on age | Correct: age is not a modifiable risk factor in the intervention context |

## 6. Evaluation Protocol

For Epic 10 (Causal Structure Learning):

1. **Fit** DoWhy intervention-based causal model on `synthetic_trajectories_train.pkl`
2. **Estimate** `ATE(do(node), fall_risk)` for each of the 4 candidate root causes
3. **Rank** nodes by absolute estimated effect on `fall_risk`
4. **Compare** ranked list against `ground_truth_root_cause` from `scm_ground_truth.json`
5. **Metrics**: Top-1 accuracy, Top-3 accuracy, Mean Reciprocal Rank (MRR)
6. **Baseline**: Attention-weight saliency from forecasting transformer (Ablation #2)
7. **Gate**: `causal_top1 > saliency_top1` AND `causal_top3 > saliency_top3` (Epic 10b.9)
